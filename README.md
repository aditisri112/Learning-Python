# Learning-Python 🐍

A collection of beginner-friendly Python scripts written while learning the core fundamentals of the language. Each file focuses on a single concept, making it easy to browse, run, and use as a quick reference.

## 📂 Contents

| File | Topic |
|------|-------|
| `variables.py` | Declaring and using variables |
| `operators.py` | Arithmetic, comparison, and logical operators |
| `conditioinal_statements.py` | `if` / `elif` / `else` conditional logic |
| `for_loop.py` | `for` loops and iteration |
| `while_loop.py` | `while` loops |
| `functions.py` | Defining and calling functions |
| `input.py` | Taking user input |
| `conversion.py` | Type conversion / casting |
| `strings.py` | String manipulation and methods |
| `list.py` | Working with lists |
| `tuple.py` | Working with tuples |
| `set.py` | Working with sets |
| `dict.py` | Working with dictionaries |
| `sum.py` | Sum-related practice program |
| `program1.py` | General practice program |

## 🚀 Getting Started

### Prerequisites
- [Python 3](https://www.python.org/downloads/) installed on your machine

### Running a script
Clone the repo and run any file with Python:

```bash
git clone https://github.com/aditisri112/Learning-Python.git
cd Learning-Python
python3 variables.py
```

Replace `variables.py` with the name of any script you'd like to explore.

## 🎯 Purpose

This repository serves as a personal learning log for practicing Python basics — a good starting point for anyone new to the language who wants to see simple, focused examples of each core concept.
